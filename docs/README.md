## Building the Docs

This documentation is built with Docusaurus:

```bash
cd docs
npm install
npm run start
```

Visit http://localhost:3000 to view the documentation locally.

## Deployment

Documentation is automatically deployed to https://zprivacy402.com/docs on every commit to the main branch.
